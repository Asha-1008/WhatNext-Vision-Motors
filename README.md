# WhatNext Vision Motors

## Salesforce CRM Project

**WhatNext Vision Motors: Shaping the Future of Mobility with Innovation and Excellence** is a Salesforce-based CRM project designed to manage vehicle sales, customers, dealers, orders, test drives, and service requests.

## Key Features

* Vehicle and stock management
* Customer management
* Dealer management
* Vehicle order processing
* Automatic stock validation
* Automatic dealer assignment
* Test drive scheduling and reminders
* Service request management
* Reports and dashboards

## Salesforce Technologies

* Salesforce Lightning
* Custom Objects and Fields
* Salesforce Flows
* Apex Classes
* Apex Triggers
* Batch Apex
* Scheduled Apex
* Reports and Dashboards

## Custom Objects

* Vehicle
* Dealer
* Customer
* Vehicle Order
* Test Drive
* Service Request
